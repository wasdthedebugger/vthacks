# Persist.health

Try it live at https://persist.health

**AI-powered clinical decision support for longitudinal patient health data.**

Persist.health helps clinicians understand patient trends across:

- 🧠 Mood, anxiety & energy
- 😴 Sleep & sleep quality
- ❤️ Heart rate & HRV
- 🫁 Breathing rate
- 📊 Check-in compliance
- 📝 Patient journals
- 🤖 AI-generated clinical reports

## Clinical Matches


```text
Patient data → AI report → Clinical matches
                         ↓
                  Relevant resources
```

The platform concept allows pharmaceutical and healthcare companies to sponsor placement while keeping sponsorship clearly disclosed and separate from the clinical analysis. Which is only visible to the healthcare provider and also included non-sponsored products. Its just a top shelf method.

## Tech Stack

- React
- Express.js
- Node.js
- Database-backed patient data
- AI-generated reports
- Responsive clinician dashboard

## Status

🚧 **Prototype / Hackathon Project**

Currently uses demo patient data and simulated clinical matches. Not intended for real clinical use without additional security, regulatory, and compliance work.

## Vision

**Make longitudinal patient data easier to understand, so clinicians can spend less time piecing together history and more time talking with patients.**
